Set up the engine

YuE Studio runs the YuE2 model on your machine through ComfyUI. The first run installs ComfyUI and downloads about 5 GB of model files, then starts on its own every time after.

Missing Python, Git or ffmpeg? The Engine page installs them for you — a new Python needs YuE Studio restarted before it is picked up.
