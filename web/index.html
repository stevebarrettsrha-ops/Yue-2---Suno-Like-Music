Set up the engine

YuE Studio runs the YuE2 model on your machine through ComfyUI. The first run installs ComfyUI and downloads about 5 GB of model files, then starts on its own every time after.

Missing Python, Git or ffmpeg? The Engine page installs them for you — a new Python needs YuE Studio restarted before it is picked up.

Settings

Where the engine lives and how it starts.

Where songs are downloaded to and loaded from. Point it anywhere — a ComfyUI YuE Studio starts is told to read it. A ComfyUI you start yourself is not, so set the same folder there too.

Lyric writer optional

A chat model that writes lyrics, a style and a title from a line about the song. Ollama and LM Studio run on this computer and need no key; cloud services do. A local writer shares the graphics card with YuE2: Ollama is told to unload after each write, but a model you load by hand in LM Studio stays in memory and slows songs down until you unload it.
